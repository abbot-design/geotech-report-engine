Geotech Report EngineQuick manual for engineers. One page, everything you need.

What it is

A web app that installs on your phone, tablet or computer like any other app. You fill in a geotechnical report section by section, on site or back at the office, and it builds the certifier-ready PDF: cover, contents, numbering, appendices, the lot. Everything saves as you type, with or without a signal.

Install once on each device

iPhone / iPad (Safari)

  1. Open the web address in Safari
  2. Tap Share (the square with an arrow)
  3. Tap Add to Home Screen, then Add

Android (Chrome)

  1. Open the web address in Chrome
  2. Tap the ⋮ menu, top right
  3. Tap Add to Home screen or Install app

Windows / Mac (Chrome or Edge)

  1. Open the web address in the browser
  2. Click the install icon at the right end of the address bar
  3. Click Install

After installing, it opens from your home screen and works without internet. This manual is always one tap away under the ? Help button in the app.

Starting a report

  • From Quickbase (usual way): open the Geotech Report record and press Send to Report Engine. The engine opens with the client, site, author and reviewer already filled in. Check the address split into suburb, state and postcode; Quickbase keeps it as one line.
  • Pressing the button again later is safe: it reopens the same report, and if anything has changed in Quickbase it shows you what differs and asks before overwriting.
  • By hand: Home, then pick a type under Start a new report. Desktop Geotechnical Assessment, Site Classification + Wind, or Comprehensive Site Investigation. You can change the type later; hidden sections keep their data.

Filling it in

  • Walk the sections with Next, or jump anywhere from the tabs. The rail shows which sections are started, complete, or still need something.
  • Fields marked Required to issue block the final report until filled. Everything else is optional and simply left out of the document if blank.
  • Photos go straight into the photo appendix with their captions. Use JPEG: on iPhone set Settings, Camera, Formats to Most Compatible, as HEIC photos will not load.
  • PDF uploads of lab or DCP results drop their pages into the results appendix; site-plan PDFs do the same into the plans appendix. The first PDF you add needs internet once; after that it works offline.
  • Information sheets (CSIRO foundation maintenance and the like) are ticked on or off under Appendices on the Review & issue page and appear in Appendix D and the references automatically.
  • Waiting on the lab? Tick Results still pending on the Results page. The report cannot be issued while it is ticked, so nothing goes out with the numbers missing.

The workflow

  1. Draft Draft: fill everything in. Preview shows the document at any time, with a DRAFT watermark across every page.
  2. Author: on the Review & issue page, sign on screen and press Submit for review. Awaiting review
  3. Reviewer: sign, or press Request changes to send it back as a draft.
  4. Issue: from Preview, press Issue final report. The watermark comes off, the version and issue date are fixed. Issued
  5. Print: Preview, then Print / Save as PDF and choose Save as PDF as the printer. Page view shows the exact A4 pages first if you want to check them.

Any edit after submitting returns the report to draft. Any edit after issuing reopens it as a new draft version (v2, v3 and so on), so an issued PDF can never quietly drift from the data behind it.

Moving a report between devices

  • Not started yet (say, raised in the office, fieldwork on a tablet): open it and press Send to another device on the Review & issue page, then scan the QR code with the other device's camera.
  • Has photos or field data: Home, the export arrow on the report, which saves a .json file named for the site. Email or AirDrop it, then on the other device use Home, Transfer between devices, Import a report.

Things to be aware of

  • Reports live only on the device they were made on. There is no cloud copy yet, so export anything important.
  • On iPhone and iPad, always open it from the home-screen icon. Safari can clear a website's storage after a week without use; the installed app keeps it.
  • Do not clear browsing history or site data for this app: that deletes its reports. Export first if you must.
  • Deleting a report from the list is instant, with an Undo offered for a few seconds. After that it is gone.
